让模型帮你生成 DID、RDD 或 IV 方案并不难。输入一段研究背景，几秒钟内它就能给出一个看起来逻辑自洽的设计：处理组定义、对照组来源、识别假设、估计方程。难的是判断这个方案是否经得起推敲。很多研究者在这里栽跟头：把叙事自洽当成识别有效，把公式正确当成假设成立。

Angrist 与 Pischke 在 *Mostly Harmless Econometrics* 中反复强调，应用计量经济学的核心是识别、反事实与因果推断的可证伪逻辑[^1]。Scott Cunningham 的 *Causal Inference: The Mixtape* 则进一步指出，识别策略的制度基础与假设可检验性，是评估任何实证设计的起点[^2]。Athey 与 Imbens 在《经济展望期刊》的综述中讨论了现代应用计量中识别策略的评估标准与常见陷阱[^3]。NIST 的 AI 风险管理框架也提供了可审计、可测试、可治理的方法论参考[^4]。

本文把这些思路浓缩成一套可用于审计 AI 生成识别策略的检查表。

## 1. LLM 识别方案的诱惑与风险

LLM 的优势是快速铺开假设空间。它的风险在于：它倾向于生成“听起来合理”的方案，而不是“经得起反驳”的方案。具体表现为：

- 默认存在可比较的对照组，却不证明可比性；
- 把识别假设写成数学表达式，却不给出可检验的制度依据；
- 忽视数据可得性，把“想要”的变量当成“必须”的变量；
- 对失败情境避而不谈。

审计的目标，是把方案从“叙事是否优美”拉回“是否可证伪”。

## 2. 先问反事实是否存在

所有因果推断都始于一个反事实问题：如果没有接受处理，结果会怎样？AI 方案往往跳过这一步，直接给出估计方程。审计时，应首先追问：

- 对照组在制度、时点或选择机制上是否真的可比较？
- 处理组与对照组之间的差异，是否可以被其他因素解释？
- 反事实是否存在一个可被观察或合理近似的对应物？

反事实不是数学假设，而是制度事实。如果制度背景不支持某个反事实，那么再漂亮的识别策略也是空中楼阁。

## 3. 五问审计表

我们建议把每个 AI 生成的识别方案拆成五个可逐项检查的问题：

| 问题 | 检查要点 | 不通过的典型表现 |
|---|---|---|
| 处理可界定 | 处理变量能否被清晰操作化？处理强度是否一致？ | 处理定义模糊，或同一处理包含多种机制 |
| 对照可比 | 对照组与处理组在选择机制上是否满足可比条件？ | 对照组在制度上无法近似反事实 |
| 假设可检验 | 关键识别假设能否被数据或制度事实反驳？ | 假设只能被“相信”，无法被验证或证伪 |
| 数据可支撑 | 所需变量是否“必须”而非仅“想要”？样本是否足够？ | 核心变量不可得，或样本量无法支撑识别 |
| 结果可替代 | 若改变估计方法或窗口，结论是否仍成立？ | 结论对单一模型设定高度敏感 |

只要其中一项不能回答，这个方案就不应直接进入编码阶段。

## 4. 强制失败情境与最弱前提

审计时，应要求模型（或自己）完成两项任务：

1. **写出最脆弱的前提**：不是最优美的叙事，而是整个识别链条中最可能断裂的那一环。
2. **给出至少一个失败情境**：在什么现实条件下，这个方案会给出错误结论？

例如，对于一份 DID 方案，最弱前提可能是“处理前趋势平行”，失败情境可能是“处理组在政策前一年已开始受预期效应影响”。

```markdown
## 审计记录示例

识别策略：双重差分，评估某政策对地区经济增长的影响。

- 处理可界定：✅ 处理组为 2020 年起实施该政策的地区。
- 对照可比：⚠️ 需补充——政策实施地区是否为自愿加入？若如此，对照组可能无法近似反事实。
- 假设可检验：⚠️ 需补充——是否有事件研究图支持平行趋势？
- 数据可支撑：❌ 核心混淆变量“地区财政能力”不可得。
- 结果可替代：待验证——是否尝试合成控制法作为替代？

最弱前提：处理组与对照组在政策实施前的经济增长趋势平行。
失败情境：实施地区在 2018 年已因预期效应开始调整投资结构。

结论：在补充平行趋势证据与财政能力代理变量之前，不建议进入回归。
```

## 5. 人机分工的新边界

AI 与人类在识别策略设计中的分工应重新界定：

- **AI 适合**：快速铺开假设空间、生成替代设计、整理假设清单、格式化检查表。
- **人类必须做**：压缩空间、拒绝错误路径、把设计绑定到真实制度背景、承担最终识别责任。

换句话说，AI 是识别策略的“发散器”，人类是“收敛器”。没有人类的收敛，发散只是噪声。

## 6. 可复用的审计清单

建议把五问审计表保存为一个 Markdown 或 Excel 模板，每次评审 AI 方案时使用：

```markdown
## AI 识别策略审计表

- [ ] 处理可界定：处理变量操作化是否清晰？
- [ ] 对照可比：对照组是否近似反事实？
- [ ] 假设可检验：关键假设能否被数据或制度反驳？
- [ ] 数据可支撑：核心变量是否可得？样本是否足够？
- [ ] 结果可替代：是否测试了替代方法或窗口？
- [ ] 最弱前提是否被明确写出？
- [ ] 是否至少给出一个失败情境？
- [ ] 人类研究者是否已确认制度背景合理性？
```

## 7. 常见错误

- **把叙事自洽当成识别有效**：模型写得通不等于现实成立。
- **忽视制度事实**：识别策略必须嵌入具体制度背景，不能只在数学上成立。
- **让 AI 同时做发散与收敛**：收敛判断必须有人类参与。
- **审计表流于形式**：每个勾选都应附带证据或说明，而不是简单打勾。

## 8. 下一步

审计框架帮助我们拒绝错误路径，但它不能保证研究资产可以被长期复用。要让识别策略、数据与代码在学期更替后仍然可信，还需要把复现仓库当作产品来治理。下一篇将讨论为什么复现往往死在回归之前。
