## 引言

双重差分法（Difference-in-Differences，DID）是经济学实证研究中最常用的因果推断工具之一。它的吸引力在于：只要处理组和对照组在政策前的趋势足够平行，我们就可以用对照组的事后变化来估计处理组的反事实，从而得到政策的平均处理效应。

但平行趋势无法直接验证。处理组怎么定义、对照组是否受到溢出影响、政策是否被提前预期、机制如何检验——这些判断高度依赖研究者的先验知识和想象力。遗漏一个合理的威胁，就可能让整篇论文的识别策略站不住脚。

本文把 Claude 定位为**研究设计顾问**：研究者负责提出问题和做最终判断，Claude 负责快速生成候选方案、系统梳理威胁、给出可检验的预测。读完这篇教程，你能够：

1. 用结构化提示词生成多种处理组定义，并评估其识别逻辑；
2. 从“图形检验”推进到“威胁清单 + 可证伪的平行趋势论证”；
3. 检查溢出效应和预期效应，并据此调整样本或模型；
4. 把处理效应拆解成有理论依据的机制；
5. 形成一份可复现、可辩护的稳健性规划。

如果你正在从一个研究想法起步，想先把整体结构搭起来，也可以先用 [research-planning](/skills/lingzhi227/agent-research-skills/research-planning) 梳理论文框架，再进入下面的 DID 设计细节。

## 前置条件

- 一个可用的 Claude（Anthropic）账号，或能通过 API / Claude Code 调用 Claude；
- 明确的研究问题、政策冲击（或事件）和结果变量；
- 已准备好面板数据的大致结构（单元、时间、处理状态）；
- 熟悉 DID 基础：双向固定效应（TWFE）、事件研究法、平行趋势假设。

## 工作流概览

整个设计过程分为五步，每一步都对应一组给 Claude 的角色提示：

| 步骤 | Claude 的角色 | 核心任务 |
|-----|--------------|---------|
| 1 | 识别策略顾问 | 生成并评估处理组定义方案 |
| 2 | 计量经济学审查员 | 论证平行趋势的合理性，列出威胁清单 |
| 3 | 产业组织经济学家 | 检查溢出效应与预期效应 |
| 4 | 机制分析顾问 | 提出作用机制与可检验预测 |
| 5 | 稳健性审查员 | 生成稳健性检验清单与预注册建议 |

下面逐节展开。每节都给出可直接复制、按需修改的提示词模板。

## 步骤一：处理组定义——不要让“按州分”成为唯一选项

处理组定义决定了识别策略的起点。最直观的定义往往来自政策文本，但它未必是最能讲故事、也最能满足识别假设的定义。Claude 的作用是在几分钟内帮你穷尽几种替代方案，并指出各自的 trade-off。

### 1.1 提示词模板

```
你是一位劳动经济学/公共经济学专家，熟悉双重差分法（DID）的识别逻辑。

我正在研究：{政策名称} 对 {结果变量} 的影响。
政策生效时间：{YYYY-MM}。
可使用的面板数据：{单元（如企业、县、个人）}，{时间频率}，{时间跨度}。

请完成以下任务：
1. 提出 5 种不同的处理组定义方案。每种方案基于不同的识别逻辑（例如：按是否受政策影响、按处理强度、按地理接近度、按行业暴露度、按处理时间先后等）。
2. 对每种方案，说明：
   - 处理组与对照组的划分规则；
   - 优点与潜在问题；
   - 满足平行趋势假设的可能性（高/中/低），并给出理由；
   - 是否适合作为主回归或稳健性检验。
3. 推荐一种主方案，并说明如果平行趋势受到质疑时，应优先改用哪种替代方案。

请以表格形式输出。
```

### 1.2 案例：最低工资提高（Card & Krueger, 1994）

以新泽西州 1992 年最低工资提高为例，Claude 可能给出如下方案：

| 方案 | 处理组定义 | 识别逻辑 | 优点 | 潜在问题 | 平行趋势可能性 |
|-----|-----------|---------|------|---------|--------------|
| A | 新泽西州所有快餐店 | 政策文本直接对应 | 最直观，符合政策描述 | 处理强度差异大 | 中 |
| B | 新泽西州初始工资低于新最低工资的店 | 处理强度明确 | 处理效应更同质 | 可能存在事前选择 | 中低 |
| C | 新泽西州边境县快餐店 vs 宾州边境县快餐店 | 地理接近，可比性强 | 对照组与处理组经济环境相似 | 样本小，跨州通勤带来溢出 | 高 |
| D | 多个同期提薪州 vs 未提薪州 | 扩大样本量 | 统计功效高 | 处理时点不一致，异质性处理时机 | 中 |
| E | 新泽西全州快餐店 vs 宾州全州快餐店，排除边境县 | 减少溢出 | 对照组更“干净” | 对照组代表性可能不足 | 中 |

**研究者的判断**：方案 C（border county design）通常作为主讲故事的设计，因为它最大程度压缩了州级经济周期差异；方案 A 和 E 则应作为稳健性检验，用来验证结论不依赖于样本选择。

### 1.3 多期 DID 的特别提醒

如果你的政策在不同地区分批实施（staggered adoption），处理组定义还要考虑**处理时机异质性**。 Goodman-Bacon (2021) 指出，TWFE 在两组 DID 比较中会对已经处理过的单元赋予负权重。Callaway & Sant'Anna (2021) 提供了按组-时计算平均处理效应的替代估计量。让 Claude 在多期设定下帮你思考时，可以追加问题：

- 哪些单元被较早处理？它们的处理效应是否可能与晚处理单元不同？
- 是否有“从未处理”或“最后处理”的单元可以作为干净对照组？
- 是否需要报告异质性处理时下的事件研究系数，而不是单一 TWFE 系数？

## 步骤二：平行趋势论证——从“看图”到“列威胁”

事件研究图只能告诉你：在政策前，处理组和对照组的趋势是否看起来平行。它不能告诉你：如果不平行，原因是什么；也不能告诉你：哪些不可观测的时变混淆因素可能破坏识别。

因此，平行趋势不能只靠统计检验，而要靠**结构化的识别论证**。Claude 的角色是帮你列出所有可能的威胁，并给出检验和修正方案。

### 2.1 提示词模板

```
你是一位严格的计量经济学审查员，专门审查 DID 的识别假设。

研究设定：
- 处理组：{描述}
- 对照组：{描述}
- 结果变量：{变量}
- 政策实施时间：{YYYY-MM}
- 时间跨度：{起始时间} 至 {结束时间}
- 数据频率：{年度/季度/月度}

请完成以下任务：
1. 列出 5-7 个可能违反平行趋势的因素。对每个因素说明：
   - 作用机制；
   - 如何用数据检验它是否造成偏误；
   - 如果存在该威胁，如何在模型或样本层面修正。
2. 给出事件研究法（event study）的推荐设定，包括：
   - 基准期选择；
   - 是否包含相对时间 -1 期；
   - 对预期效应的处理方式；
   - 系数解释与置信区间展示方式。
3. 评估整体识别策略的可信度（1-10 分），并给出 3 条具体改进建议。

请用分点方式输出，每条包含“机制/检验/修正”三个部分。
```

### 2.2 常见威胁与应对思路

针对 Card & Krueger 式的新泽西-宾州设计，Claude 通常会列出：

1. **区域特定冲击**：两州经济周期不同。
   - 检验：比较政策前 5 年就业趋势；加入州-时间交互固定效应。
   - 修正：交互加权 DID、合成控制法。

2. **行业特定冲击**：快餐行业在全国层面出现趋势变化。
   - 检验：比较其他州快餐店趋势。
   - 修正：加入行业-时间固定效应；使用全国未受影响行业作为额外对照。

3. **预期效应**：雇主在政策生效前调整雇佣。
   - 检验：事件研究中加入政策宣布前的 lead 系数。
   - 修正：以政策宣布而非生效作为事件时间；剔除宣布到生效之间的过渡期。

4. **选择进入处理组**：某些县更容易提高最低工资。
   - 检验：比较处理县与未处理县的事前协变量平衡。
   - 修正：加入协变量、匹配或加权。

5. **结果变量测量误差**：就业统计口径在两州不一致。
   - 检验：核对数据来源与变量定义；使用替代结果变量。
   - 修正：稳健性检验中使用不同就业口径。

**关键原则**：平行趋势的论证是一个“可证伪”的过程。Claude 帮你列出威胁后，你必须用数据和文献逐项排除，而不是让模型替你下结论。

## 步骤三：溢出效应与预期效应检查——SUTVA 不是免费的

DID 隐含要求处理组的行为不会影响对照组（无溢出），且对照组的状态不会提前因政策而改变（无预期）。这两个假设在政策影响范围大、地理边界模糊、信息传播快的场景中尤其容易被违反。

### 3.1 提示词模板

```
你是一位产业组织经济学专家，研究市场、地区或个体之间的相互影响。

研究设定：
- 处理组：{描述}
- 对照组：{描述}
- 市场结构：{竞争性/寡头等}
- 地理范围：{州、县、城市、边境等}
- 政策信息是否提前公开：{是/否，提前多久}

请完成以下任务：
1. 列出所有可能的溢出渠道：劳动力流动、消费者跨区购买、企业迁移/进入退出、投入产出关联、价格传导、信息/网络效应等。
2. 对每个渠道：
   - 说明作用机制与预期影响方向；
   - 给出可在数据中观察到的“痕迹”；
   - 建议检测方法（如空间 DID、排除边界样本、工具变量等）。
3. 列出预期效应（anticipation）的可能表现，并给出事件研究法中如何检验 leads。
4. 如果溢出或预期效应严重，建议样本调整或模型修正方案。

请以“渠道 - 机制 - 痕迹 - 检测 - 修正”的表格输出。
```

### 3.2 溢出效应的检测与修正

以最低工资为例，主要溢出渠道包括：

| 渠道 | 机制 | 数据痕迹 | 检测方法 | 修正方案 |
|-----|------|---------|---------|---------|
| 劳动力跨州通勤 | 新泽西工资提高吸引宾州工人 | 宾州边境县就业下降 | 比较边境县与非边境县 | 排除通勤便利县；使用通勤流定义处理强度 |
| 消费者跨区消费 | 宾州消费者到新泽西消费 | 新泽西边境销售额上升 | 比较销售额变化 | 谨慎解释销售额结果；加入销售额作为控制 |
| 企业选址/迁移 | 企业迁往成本更低的对照地区 | 宾州企业进入增加、新泽西退出增加 | 企业进入退出面板 | 使用短期静态效应；长期动态模型 |
| 价格传导 | 成本上升传导至产品价格 | 新泽西快餐价格相对上升 | 价格面板 | 控制价格变量；使用实际工资 |

### 3.3 预期效应的处理

预期效应会让“政策前”的对照组状态已经发生变化，从而污染反事实。检测方法：

- 在事件研究中加入政策前若干期的 lead 系数；
- 如果 lead 系数显著不为零，说明存在预期；
- 可将政策**宣布时间**作为事件时间重新估计；
- 或删除政策宣布到生效之间的样本，把这段时间视为“调整期”。

## 步骤四：机制分析——从“显著”到“为什么显著”

机制分析不是事后讲故事，而是要在估计主效应之前，就提出理论上可解释、数据上可检验的机制。Claude 可以帮助你把机制拆分成竞争假设，并设计对应的实证策略。

### 4.1 提示词模板

```
你是一位劳动经济学/公共经济学专家，研究政策传导机制。

研究问题：{问题}
主要发现（待验证）：{处理效应方向与大小}
数据可用变量：{变量列表}

请完成以下任务：
1. 提出 4-6 个可能的作用机制。对每个机制：
   - 给出理论依据（引用经典文献或理论）；
   - 设计检验该机制的实证策略（回归设定、子样本、交互项、中介变量等）；
   - 说明如果该机制成立，应在数据中看到什么；
   - 说明如果该机制不成立，应看到什么。
2. 讨论机制之间的替代、互补或同时成立关系。
3. 推荐 2-3 个最值得优先检验的机制，并说明理由。
4. 建议可能的中介变量或调节变量，以及它们在回归中的位置。

请以结构化的方式输出，每个机制包含“理论/检验/预测/优先度”。
```

### 4.2 最低工资就业效应的可能机制

针对“最低工资提高后快餐业就业没有显著下降”这一发现，Claude 可能提出：

1. **劳动力供给增加**：更高工资吸引工人进入劳动力市场。
   - 检验：劳动力参与率、职位申请数。
   - 预测：就业增加或保持不变，人均工时可能下降。

2. **企业成本转嫁**：企业提高产品价格，需求下降被抵消。
   - 检验：价格变化和销售额变化。
   - 预测：价格上升，销售额下降但幅度有限。

3. **效率工资效应**：更高工资激励工人更努力，生产率上升。
   - 检验：销售额/员工数、离职率。
   - 预测：生产率上升，离职率下降。

4. **资本替代劳动**：企业用自动化设备替代低技能工人。
   - 检验：资本投资、技能结构变化。
   - 预测：低技能就业下降，资本支出上升（长期效应）。

5. **市场集中度与议价能力**：大企业能承受成本冲击，小企业退出。
   - 检验：企业规模异质性、市场集中度变化。
   - 预测：大企业就业稳定，小企业就业下降。

**研究者的判断**：机制分析最怕“什么都可能”。Claude 列出一堆机制后，你要根据理论重要性和数据可得性，优先检验 2-3 个。如果一个机制无法被证伪，就不要写进论文。

## 步骤五：稳健性规划——在跑回归之前先写好检查清单

稳健性检验不是主回归跑完后的“补丁”，而应该在设计阶段就规划好。Claude 可以帮你生成一份可执行的稳健性清单，避免遗漏。

### 5.1 提示词模板

```
你是一位严谨的实证经济学审稿人，专门审查 DID 研究的稳健性。

研究设定：{简述}
主回归模型：{例如 TWFE、Callaway-Sant'Anna、堆叠 DID 等}
处理组定义：{方案}

请完成以下任务：
1. 生成一份至少 8 项的稳健性检验清单，覆盖：
   - 处理组定义的替代方案；
   - 对照组选择的替代方案；
   - 时间窗口变化（缩短/延长、排除政策前后若干期）；
   - 样本限制（排除极端值、边境县、特定行业）；
   - 协变量与固定效应设定；
   - 标准误聚类层级；
   - 安慰剂检验与置换检验；
   - 异质性处理时机下的替代估计量。
2. 对每项检验，说明：
   - 目的；
   - 具体操作；
   - 通过标准（什么结果支持主结论）。
3. 指出哪些检验必须在主回归前完成，哪些可以在主回归后补充。
4. 给出预注册（pre-analysis plan）的核心条目建议。

请用清单（checklist）格式输出。
```

### 5.2 稳健性清单示例

| 编号 | 检验 | 操作 | 通过标准 |
|-----|------|------|---------|
| 1 | 替代处理组定义 | 使用方案 B、C、D 分别回归 | 系数方向与显著性一致 |
| 2 | 替代对照组 | 使用全州样本、仅非边境县、合成控制 | 基准结果稳健 |
| 3 | 时间窗口 | 前后各延长/缩短 2 年 | 结果不依赖窗口选择 |
| 4 | 排除边界县 | 去掉处理组与对照组边境 50 公里内样本 | 系数无明显变化 |
| 5 | 协变量设定 | 加入单元特征与趋势交互项 | 主系数稳定 |
| 6 | 标准误聚类 | 在县/州两级聚类；Conley 空间标准误 | 显著性结论不变 |
| 7 | 安慰剂检验 | 随机分配处理状态 500 次 | 安慰剂系数集中分布在 0 附近 |
| 8 | 替代估计量 | Callaway-Sant'Anna、堆叠 DID | 与 TWFE 方向一致 |

## 可复制的工作流：把 Claude 接入代码

下面是一个最小可运行的 Python 脚本。它使用 Anthropic 官方 SDK，把上述五步封装成一个 `ClaudeDIDPartner` 类。研究者只需替换研究设定和提示词，即可批量生成设计备忘录。

```python
import os
from anthropic import Anthropic

class ClaudeDIDPartner:
    def __init__(self, api_key: str = None, model: str = "claude-sonnet-4-20250514"):
        self.client = Anthropic(api_key=api_key or os.environ.get("ANTHROPIC_API_KEY"))
        self.model = model

    def ask(self, system: str, prompt: str, max_tokens: int = 2500) -> str:
        message = self.client.messages.create(
            model=self.model,
            max_tokens=max_tokens,
            system=system,
            messages=[{"role": "user", "content": prompt}]
        )
        return message.content[0].text

    def step1_treatment_definitions(self, policy: str, outcome: str, context: str) -> str:
        system = "你是一位熟悉 DID 的识别策略顾问。输出用表格，重点比较不同处理组定义对平行趋势的影响。"
        prompt = f"""我正在研究 {policy} 对 {outcome} 的影响。
研究背景：{context}
请按步骤一提示词模板生成 5 种处理组定义方案，并推荐主方案。"""
        return self.ask(system, prompt)

    def step2_parallel_trends(self, treatment: str, control: str, outcome: str,
                              time_span: str, policy_time: str) -> str:
        system = "你是一位严格的计量经济学审查员。列出平行趋势威胁时必须给出检验和修正方法。"
        prompt = f"""处理组：{treatment}
对照组：{control}
结果变量：{outcome}
时间跨度：{time_span}
政策实施时间：{policy_time}
请按步骤二提示词模板评估平行趋势可信度。"""
        return self.ask(system, prompt)

    def step3_spillovers(self, treatment: str, control: str,
                         market: str, geography: str) -> str:
        system = "你是一位产业组织经济学家，专门分析市场间的溢出效应。输出用渠道-机制-检测-修正表格。"
        prompt = f"""处理组：{treatment}
对照组：{control}
市场结构：{market}
地理范围：{geography}
请按步骤三提示词模板检查溢出与预期效应。"""
        return self.ask(system, prompt)

    def step4_mechanisms(self, question: str, finding: str) -> str:
        system = "你是一位机制分析顾问。每个机制必须包含理论依据、检验策略和可证伪预测。"
        prompt = f"""研究问题：{question}
主要发现：{finding}
请按步骤四提示词模板设计机制分析。"""
        return self.ask(system, prompt)

    def step5_robustness(self, design: str, model: str, treatment_def: str) -> str:
        system = "你是一位严谨的实证审稿人。生成可执行的稳健性检验清单。"
        prompt = f"""研究设定：{design}
主回归模型：{model}
处理组定义：{treatment_def}
请按步骤五提示词模板输出稳健性清单与预注册建议。"""
        return self.ask(system, prompt)

    def run_pipeline(self, config: dict, output_path: str = "did_design_memo.md"):
        sections = [
            ("步骤一：处理组定义", self.step1_treatment_definitions(
                config["policy"], config["outcome"], config["context"])),
            ("步骤二：平行趋势论证", self.step2_parallel_trends(
                config["treatment"], config["control"], config["outcome"],
                config["time_span"], config["policy_time"])),
            ("步骤三：溢出与预期效应", self.step3_spillovers(
                config["treatment"], config["control"], config["market"], config["geography"])),
            ("步骤四：机制分析", self.step4_mechanisms(
                config["question"], config["finding"])),
            ("步骤五：稳健性规划", self.step5_robustness(
                config["design"], config["model"], config["treatment"])),
        ]
        with open(output_path, "w", encoding="utf-8") as f:
            for title, content in sections:
                f.write(f"## {title}\n\n{content}\n\n")
        print(f"设计备忘录已保存至：{output_path}")

# 使用示例
if __name__ == "__main__":
    partner = ClaudeDIDPartner()
    config = {
        "policy": "新泽西州 1992 年最低工资提高",
        "outcome": "快餐业就业",
        "context": "1992 年 4 月，新泽西州将最低工资从 4.25 美元提高到 5.05 美元。数据为 1992-1993 年新泽西与宾州快餐店面板。",
        "treatment": "新泽西州快餐店",
        "control": "宾夕法尼亚州快餐店",
        "time_span": "1992-1993",
        "policy_time": "1992-04",
        "market": "竞争性劳动力市场",
        "geography": "新泽西-宾州边境",
        "question": "最低工资提高对快餐业就业的影响",
        "finding": "就业未显著下降，甚至可能略有上升",
        "design": "新泽西-宾州边境县 DID",
        "model": "双向固定效应（TWFE）事件研究法"
    }
    partner.run_pipeline(config)
```

运行后，你会得到一个 `did_design_memo.md` 文件。不要直接把它当作最终论文段落，而要把它当作**讨论稿**：逐条审视、删去不成立的威胁、补充数据证据，再写入论文。

在把设计整理成规范论文段落时，可以配合使用 [econ-write](/skills/hanlulong/econ-writing-skill/econ-write) 来检查经济学写作的常见结构和表达。

## 人机协作边界

| 任务 | Claude 适合 | 研究者必须做 |
|-----|-----------|-----------|
| 生成处理组方案 | 头脑风暴、列出 trade-off | 最终选择、基于理论 justify |
| 平行趋势论证 | 列出威胁清单、建议检验 | 用数据逐项验证、下结论 |
| 溢出/预期效应 | 提出可能渠道 | 数据检测、样本调整 |
| 机制分析 | 理论框架、可检验预测 | 选择优先机制、实证检验 |
| 稳健性规划 | 生成 checklist | 执行并解释结果 |

**三个不要**：

1. **不要**把 Claude 的评分或推荐直接当作结论。模型的判断基于训练数据中的模式，而不是你手头的数据。
2. **不要**在提示词中放入未发表结果、敏感数据或保密信息。
3. **不要**忽视知识截止日期。对于最新政策，必须在提示词中提供充分上下文。

## 下一步

完成 DID 设计备忘录后，下一步通常是：

1. 把备忘录中的处理组定义和数据要求写入预分析计划（pre-analysis plan）；
2. 在 Stata / Python 中实现基准回归与事件研究；
3. 用 Agent 工具链（例如 [claude-code-stata-mcp](/blog/claude-code-stata-mcp)）把自然语言设计转化为可运行代码。
