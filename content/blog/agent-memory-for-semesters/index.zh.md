很多团队把 Agent 记忆等同于向量检索，但在研究场景里，更难也更重要的是保存选择过程、失败尝试和放弃原因。

## 把记忆分成事实、判断和制度三层

事实层保存变量定义、数据口径和引用来源；判断层保存为什么采用某个识别策略；制度层则记录导师偏好、课程目标或合作规范。这三层不能混写。

## 记忆条目必须带时间戳和失效条件

研究环境会变化。数据更新、课程轮替、政策背景改变，都可能让旧结论失效。没有失效条件的记忆，最终会污染整个系统。

## 最好的记忆系统，总能把人带回原始证据

不要让记忆层变成新的黑箱。每一条重要结论都应该能回链到笔记、脚本、论文或数据文件，让后来者可以重新判断，而不是只能被动接受。
